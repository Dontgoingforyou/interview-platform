# UX-прототип

Статический прототип фиксирует карту существующего React-интерфейса. Он не заменяет
production UI и обновляется только вместе с видимыми UX-требованиями.

Открыть локально:

```bash
npx serve docs/product/prototype/pages
```

Источники: `input.json`, `pages-index.md`, `../screens-index.md`.
