# Перенос фронтенда на React — оценка объёма

Историческая оценка. Текущий вход — локальные демо-учётки, без внешнего SSO.

## Масштаб проекта

- **88** HTML-шаблонов (из них ~25 партициалов)
- **37** JS-файлов
- **34** CSS-файла
- **11** Django-форм в 7 приложениях
- **14** приложений Django

---

## Архитектура после миграции

```
React SPA                          Django Backend
─────────────────────────────      ─────────────────────
React Router                       DRF REST API
    │                                   │
Компоненты                         PostgreSQL
    │
Zustand / Context
    │
Axios API Client ──── сессия ──────────► DRF
```

**Изменения в бэкенде:**

- Все Django-views превращаются в DRF API endpoint-ы (большинство уже есть)
- Django отдаёт один `index.html` для React (точка входа)
- Шаблоны удаляются после переноса

- **E2E с API:** для проверки данных поднять Django на `:8000` (proxy Vite); иначе смоки проверяют только каркас SPA при dev-обходе SSO.

## Чеклист: новая вкладка (раздел) в React SPA

1. **Маршрут** — добавить `Route` в [`frontend/src/appRoutes.tsx`](../frontend/src/appRoutes.tsx) (или заменить `PagePlaceholder` на страницу-фичу). Тяжёлые страницы подключать через `React.lazy` + `Suspense` (как `InterviewFormPage`).
2. **Страница** — `frontend/src/pages/<приложение>/…tsx` (список, форма и т.д.).
3. **API** — `frontend/src/api/<приложение>Api.ts`, вызовы через [`apiClient`](../frontend/src/api/client.ts).
4. **Типы** — `frontend/src/types/<сущность>.ts`; для списков с пагинацией DRF — [`Paginated<T>`](../frontend/src/types/common.ts).
5. **Данные** — TanStack Query в хуке `hooks/<приложение>/use….ts`, ключи вида `['debts', 'list', filters]`.
6. **Стили** — по возможности общие классы из [`components.css`](../frontend/src/styles/components.css) и [`tables.css`](../frontend/src/styles/tables.css); специфику раздела — отдельный файл (`styles/<приложение>.css`) с импортом из страницы или через `index.css`.
7. **UI** — переиспользовать [`components/ui/`](../frontend/src/components/ui/) (`PageTitle`, `PageIntroCard`, `PageHeaderActions`, `TableScroll`, `DataTable`, `ListPageFilterForm`, `MetricCard`, `MetricsGridSection`, `ImportModal`, `LoadingLine`, `InlineError`).
8. **Навигация** — пункт уже в [`constants/navigation.ts`](../frontend/src/constants/navigation.ts); убедиться, что путь совпадает с `path` в роутере.
