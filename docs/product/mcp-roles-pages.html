MCP: кто что может

HTTP MCP POST /mcp

Реализован полный набор тулов по согласованной матрице. Права совпадают с UI/API. Mentor — allowlist (база собеседований + транскрипции). Офферы / долги / KPI / admin-разработчики — только admin. Права совпадают с локальными демо-ролями.
