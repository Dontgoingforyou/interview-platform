# Нормативные требования к тестам

- Тесты детерминированы и не ходят во внешние сервисы.
- Изменение поведения сопровождается автотестом.
- Изменение API сопровождается API-тестом и обновлением OpenAPI.
- Секреты заменяются фикстурами и тестовыми значениями.
- Риск A из `docs/product/test-cases.md` должен иметь автоматическую проверку.

Порог покрытия бэкенда не задан. Отчёт и команды: `docs/product/coverage.md`.

```bash
make test
make coverage
make test-frontend
cd project/frontend && npm run test:e2e
```
